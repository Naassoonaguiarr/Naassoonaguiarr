## 🚀 Sobre mim

Desenvolvedor fullstack focado em criar solucoes completas — do frontend ao hardware. Trabalho com apps desktop (Tauri/Rust), plataformas web (React/Supabase) e sistemas embarcados (ESP32/LoRa).

- 🔭 **Projetos ativos:** [Embarquetur](https://github.com/Naassoonaguiarr/meu-app) · [NFX Sistema](https://github.com/Naassoonaguiarr/nfx)
- 🌱 **Stack principal:** React · Tauri · Supabase · ESP32
- 🎯 **Foco atual:** Plataformas completas com comunicacao hardware-software
- 📍 **Regiao:** Amazonia, Brasil
